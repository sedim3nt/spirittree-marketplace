# SpiritTree Marketplace

The original AgentOrchard marketplace — AI operations consulting and agent configurations.

**Live:** (Superseded by [agentorchard.dev](https://agentorchard.dev))
**Stack:** Static HTML/CSS
**Status:** Archive

## What This Is

SpiritTree Marketplace was the original static HTML version of what became AgentOrchard. It includes product browsing, consulting pages, blog, and account management — all built as a multi-page static site with elegant Cormorant typography and a clean, editorial design.

This version has been superseded by the Next.js-based AgentOrchard app but remains as a reference for the original design direction and content structure.

## Features

- 🛍️ **Product Browsing** — marketplace grid with filtering
- 💼 **Consulting Page** — service offerings and pricing
- 📝 **Blog** — content marketing pages
- 👤 **Account System** — login/register/forgot-password pages
- 📖 **About Page** — mission and team information
- 🎨 **Editorial Design** — Cormorant serif typography, cream/navy palette
