Multi-Agent Communication Architecture Guide

Architecture

About

Three architecture patterns for scaling from a single AI agent to a coordinated multi-agent system. Includes the token relay tax analysis, cross-agent memory coordination protocols, and a decision framework for choosing the right pattern.

Covers the CEO model (single agent), topic threads (isolated contexts per domain), and separate bots (maximum isolation). With real cost math showing when each pattern makes sense.

Built from production experience running 8 agents across coding, research, content, ops, and blockchain workstreams. Not theory — tested coordination patterns with specific failure modes and mitigations documented.

What's Included

  • 3 architecture patterns with diagrams and trade-offs
  • Token relay tax analysis with real cost math
  • BULLETIN.md cross-agent announcement protocol
  • Status file protocol (JSON per agent)
  • Shared workspace layout with handoffs/ and entities/
  • OpenClaw topic thread configuration examples
  • Decision framework: when to use each pattern
  • 3-month migration path from single to multi-agent
  • Model-per-topic cost optimization strategy
  • Race condition mitigations for shared workspaces
  • Cron job targeting by topic/domain
