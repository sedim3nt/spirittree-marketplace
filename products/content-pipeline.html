Content Pipeline System

Multi-agent writing, editing, and publishing pipeline

Digital Product

About

The Content Pipeline System is the multi-agent workflow used to produce and distribute SpiritTree's content operation. Four agents in sequence: research, write, edit, publish. Each with a defined role, clear inputs, and verifiable outputs.

The research agent monitors topic signals — X, newsletters, GitHub, search trends — and surfaces the highest-leverage topics for your audience and positioning. The content agent writes the first draft. The editor agent tightens it against your brand voice guidelines. The publisher agent distributes to all configured platforms.

Platform coverage: Substack for long-form, X/Twitter for threads and singles, Facebook for community distribution, Instagram for visual content. Each platform has its own formatting and scheduling configuration.

Includes a content calendar template and a brand voice guidelines template you fill in once. The system references it on every content job, keeping output consistent across agents and over time.

What's Included

  • Multi-agent writing pipeline config
  • Research → Draft → Edit → Publish workflow
  • Substack publishing automation
  • X/Twitter posting automation
  • Facebook cross-posting config
  • Content calendar template
  • Brand voice guidelines template
